# Grillo UX prototype (PRD v1, releases 1 to 3)

The eight release-1 screens of `docs/PRDs/PRD.md` section 5, plus the public download site of section 8 (a web page, not a version of Grillo), in the PRD's **liquid glass** theme (section 9). Release 2 and 3 additions (section 5 last paragraph, section 12) are two more screens and new states on existing screens; the table marks them.

Open `index.html` straight from disk in any browser: no build step, no network. The left-hand list switches screens and the "States" buttons switch each screen's states; the "Windows fallback" switch turns off the frosted blur to check readability where it is unavailable. A link `#<screen id>/<state>` opens a screen in one state (for example `#screen-project-creation/structure`). The ids in backticks in the States column are the state names the release 2 and 3 additions use (for example `#screen-prd-view/score`).

Front-end stories take every colour and spacing value (and every radius, blur and size) from `tokens.css` and nothing else; `index.html` holds a copy of it.

Front-end stories reference a screen by its id.
