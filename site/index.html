Grillo

From the first statement of an idea, through a guided grilling of the right experts, to a finished, traceable PRD. A desktop app for Windows and Mac.

Download for Windows Download for Mac All releases on GitHub

The latest release and its installers are on GitHub.

What Grillo is

  • Experts answer only the questions for their domain, live or in their own time.
  • Answers are recorded with their discussion, on your own laptop.
  • Every line of the PRD traces back to who said it, when and where.

What you need first

  • Claude Code, signed in with your own Claude subscription (any plan).
  • The GitHub command-line tool gh, signed in.
  • A company GitHub account.

These pilot installers are not signed yet, so Windows and Mac each show one warning the first time. This is expected; the steps below say what to click.

Install on Windows

  1. Run the Grillo-Setup .exe file you downloaded.
  2. If Windows says it protected your PC, click "More info", then "Run anyway".
  3. Open Grillo; the setup check guides you through the rest.

Install on Mac

  1. Open the Grillo .dmg file you downloaded and drag Grillo into Applications.
  2. If macOS says it cannot check the developer, open System Settings, Privacy and Security, and click "Open Anyway".
  3. Open Grillo; the setup check guides you through the rest.

How to use it

  1. Create a project and invite the people who know the subject.
  2. Give the idea as text or a transcript; Grillo turns it into a map of tickets and questions.
  3. Run the tagging round so each question reaches the right domain.
  4. Answer together in a live session, or each in your own time.
  5. When the map is done, Grillo writes the PRD; download it as Markdown or HTML.
