What Grillo is

The right experts, the right questions, a PRD you can trace

  • Only your questions

    Experts answer only the questions for their domain, live or in their own time.

  • Recorded on your laptop

    Answers are recorded with their discussion, on your own laptop.

  • Every line has a source

    Every line of the PRD traces back to who said it, when and where.

How it works

From idea to PRD in five steps

  1. 1

    Create a project

    Create a project and invite the people who know the subject.

  2. 2

    Give the idea

    Give the idea as text or a transcript; Grillo turns it into a map of tickets and questions.

  3. 3

    Tag the questions

    Run the tagging round so each question reaches the right domain.

  4. 4

    Answer together

    Answer together in a live session, or each in your own time.

  5. 5

    Get the PRD

    When the map is done, Grillo writes the PRD; download it as Markdown or HTML.

Install

Get Grillo running

Three things first, then a few clicks on Windows or Mac.

Signed for Windows and Mac: no warning to click through.

What you need first

  • Claude Code, signed in with your own Claude subscription (any plan).
  • The GitHub command-line tool gh, signed in.
  • A company GitHub account.

Install on Windows

  1. Run the Grillo-Setup .exe file you downloaded.
  2. If Windows says it protected your PC, click "More info", then "Run anyway".
  3. Open Grillo; the setup check guides you through the rest.

Install on Mac

  1. Open the Grillo .dmg file you downloaded and drag Grillo into Applications.
  2. If macOS says it cannot check the developer, open System Settings, Privacy and Security, and click "Open Anyway".
  3. Open Grillo; the setup check guides you through the rest.
